# K 線研習院

入口：`webapp/academy.html`。市場首頁、專業分析台與共用市場研究選單皆提供入口。

## 教材與互動

- 12 單元、60 課原創繁體中文教材。每課包括情境、判讀方法、確認與失效條件、觀念题、筆記與歷史觀察任務。
- 12 組多面板概念圖；課程以四階段互動 K 線拆解，提供反向發展與波動變體、並排對照。第二支腳提供高度滑桿。
- 156 組非重疊歷史案例：12 個核心分類各 10 組，6 個進階分類各 6 組。含雙低／雙高、頭肩頂底、趨勢、支撑、量能、收斂、突破、失敗突破、背離、三角、楔形、旗形、杯柄、圓弧頂底。
- 216 題判讀練習為 60 題觀念＋156 題實際歷史位置判讀。另有指定支撑畫線回饋與 12 場綜合盲測，不把圖表切換算成額外題數。
- 實際歷史案例含可追溯的數值解析、波段標記、逐根／五根回放、日週線、線性／對數軸、MA20／60、RSI、成交量、十字讀值、縮放／平移、全螢幕、水平線／斜線／價格區帶。
- 盲測先記錄再揭曉，原始判斷與畫線快照保留。學習進度、答案、錯題、收藏、筆記、畫線與自評在瀏覽器儲存，支援 JSON 匯出與合併匯入。
- 多單風險計算器包含資金、風險比例、進場／停損／目標、每股成本、交易單位與跳空壓力情境。

## 資料與誠實邊界

24 檔台美股票／ETF，共 114,028 筆有效日線；最早 2006 年、截至 2025-12-31。快照由既有 Yahoo chart 存取流程取得，独立於原網站每日行情，不會因日更使註解漂移。每檔保留来源網址、擷取時間、OHLCV 欄位與 SHA-256。

價格為來源 quote OHLC，沿用其拆併股調整口徑，未另作股息還原。資料擷取過濾缺失、非正價格、不一致 OHLC 與負量。這不等於逐筆交易所／公司行動核實；價格報酬不含股息、費用、匯率。

案例是明示規則的教學選樣，不是人工認證每個形狀完全符合經典型態，也不是全市場策略回測。每個案例附辨識數值與跨度；候選、突破、後續結果分開說明。以非重疊期間與漲跌配额挑圖，不能從案例分布推算勝率。

結果分類取觀察日到第 20 個交易日收盤報酬：>3% 上行、<−3% 下行，其餘區間。這不是實際交易獲利。每類有不同結果的獨立對照。

回放先截斷價格，再計算指標、價格軸與週線，局部轉折等右側三根確認才標記。盲測隱藏結構名稱與結果，揭曉後才能開解析。這是教育遮蔽，不是防作弊設施。

## 檔案分工

| 檔案 | 責任 |
| --- | --- |
| `academy-content.js` | 60 課正文、觀念題、章節、參考來源 |
| `academy-diagrams.js` | 合成 K 線與分階段註解 |
| `academy-plates.js` | 多面板 SVG 概念對照圖 |
| `academy-chart.js` | 已知資料圖表、週線、指標、風險計算 |
| `academy-case-notes.js` | 依各類真實案例數值產生證據解析 |
| `academy.js` | 課程／案例／練習／紀錄／資料頁的路由與互動 |
| `academy-data/catalog.json` | 案例、選樣規則、来源目錄 |
| `academy-data/history/` | 24 檔固定 OHLCV 快照 |
| `scripts/build_academy_cases.py` | 擷取與可重製案例選樣 |

重製現有快照的案例：`python3 scripts/build_academy_cases.py`。

`--fetch` 會更新來源快照，屬於新教材版本工作：需同步更新教材版本、確認案例 ID 對既有學習紀錄的影響，重新驗證後才發布。不要在每日行情排程中呼叫。
