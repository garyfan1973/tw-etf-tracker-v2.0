## 已完成的功能

入口：`webapp/analysis.html`。首頁與共用市場研究選單均可前往。

- 台、美、日、韓共 298 檔已保存歷史行情；搜尋代號或公司名稱。
- K 線／收盤走勢／相對報酬三種模式，MA20、MA60、布林通道及成交量。
- RSI14、MACD12/26/9、KD9 副圖，連動十字游標及鍵盤逐日查看。
- 1M／3M／6M／1Y／全部區間（對應 21／63／126／252 筆日線／全部歷史），滾輪縮放、拖曳平移與時間窗滑桿。
- 區間價格報酬、年化波動率、最大回撤、上漲日比例；回撤圖跟隨可視区間更新。
- 月度報酬熱圖與點擊月份查看走勢。
- 動能儀表採區間末日指標，包含均線、MACD、KD、量比。
- 以同市場個股或加權、S&P 500、Nasdaq 100、費半、日經、韓國綜合指數作比較基準。
- 本機觀察清單、20 日報酬排序／篩選、分批展開市場掃描。
- 專注模式、完整研究連結、可還原圖表設定與日期的分享連結、CSV 匯出。

## 資料與運作方式

`fetch_price_history.py` 更新歷史後呼叫 `scripts/build_analysis_catalog.py`，從保存的 OHLCV 產生 `webapp/price-history/catalog.json`。目錄放在既有 `webapp/price-history/` 自動提交路徑內，Cloud Run 批次與 GitHub 人工備援均會帶入，無須重建批次容器。新增已保存行情會在下一次生成時進入搜尋與排行；指標在瀏覽器本地計算。

目錄亦可單獨重建：

```bash
python3 scripts/build_analysis_catalog.py
```

新頁不需登入、API 金鑰或新資料庫資料表。觀察清單保存於目前瀏覽器，最多 12 檔，不同步會員關注資料。分享連結包含研究設定，不包含持股資料。

## 計算邊界

- 使用保存的日線價格，未加入即時報價；不同市場交易日期不同。
- 報酬不含股息、費用或匯率。來源價格未在本頁重新還原權息，來源調整與拆併股會影響結果。
- 所有指標先以完整歷史計算，再截取顯示；不足週期顯示缺值。EMA 以完整週期均值初始化，RSI 使用 Wilder 平滑。
- 波動率用每日對數報酬的樣本標準差乘 √252；至少需要三筆收盤。
- 比較圖只取共同交易日期，兩條線均以首個共同日為 0%；其他數據卡仍是主標的可視區間。
- 月報酬需有前一個曆月末的有效收盤；缺少前月不跨月冒算。最新月截至資料日期。
- 排行是已收錄標的最近 20 個交易區間，非全市場掃描，各筆都附日期；不同日期的排行應分別解讀。
- 指標說明參照 [TradingView RSI](https://www.tradingview.com/support/solutions/43000502338-relative-strength-index-rsi/) 及 [Historical Volatility](https://www.tradingview.com/support/solutions/43000589145-historical-volatility/)。本頁不是 TradingView 技術評等或買賣建議。
